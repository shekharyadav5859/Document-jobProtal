Project Overview

Job Portal is a backend web application developed using Java and Spring Boot. It aims to connect job seekers and hiring teams through a centralized platform for user profiles, job postings and user interactions.

The project follows a layered architecture to organize application logic, database operations and REST API endpoints. APIs can be tested using Postman or Thunder Client without downloading the project source code.

Project Features

User Authentication

Email-based OTP verification, user lookup and login functionality.

User Profile Management

Create, retrieve, update and delete user profiles.

Job Management

Companies can create, update, delete and retrieve job postings.

Follow System

Users can follow other users and view followers and following lists.

Posts and Pagination

Create posts and retrieve feeds using pagination and infinite scrolling.

Job Applications

Submit job applications and update application status.

Authentication APIs

Base path: /auth

MethodEndpointDescription
POST/auth/send-otp?email={email}Send OTP to email
POST/auth/verify-otpVerify OTP and register user
GET/auth/usersRetrieve all users
POST/auth/LoginUser login

Verify OTP and Register

{
  "email": "user@example.com",
  "password": "yourPassword",
  "otp": "123456"
}

Login Request

{
  "email": "user@example.com",
  "password": "yourPassword"

User Profile APIs

Base path: /about-user

MethodEndpointDescription
POST/about-userCreate profile
GET/about-userGet all profiles
GET/about-user/{id}Get profile by ID
PUT/about-user/{id}Update profile
DELETE/about-user/{id}Delete profile

Create Profile Request

{
  "userId": 1,
  "about": "Java Backend Developer passionate about building REST APIs",
  "education": "B.Tech in Computer Science",
  "experience": "Fresher",
  "skills": "Java, Spring Boot, MySQL, REST API",
  "location": "Indore"
}

User ID should identify the registered user.

Post APIs

Base path: /Post

MethodEndpointDescription
GET/Post/getGet all posts
GET/Post/get/{id}Get post by ID
POST/Post/saveCreate post
DELETE/Post/delete/{id}Delete post
GET/Post/user/{userId}Posts by user
GET/Post/main?lastId=0&limit=10Paginated feed

Create Post Request

{
  "userId": 1,
  "imgUrl": "https://example.com/image.jpg",
  "discription": "Learning Java and Spring Boot",
  "tittle": "My First Post"
}

Pagination parameters:

  • lastId: Last retrieved post ID (default 0).
  • limit: Number of posts per request (default 10).
